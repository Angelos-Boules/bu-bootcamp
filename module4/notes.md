### Module 4
#### Version Control with Git and GitHub
- git is a local source control tracking system
- GitHub is a cloud storage service which hosts and tracks git tracked repos, allowing sharing across teams
- Files begin in the working directory, are added into the staging area, and finally commited to the repo
- branching allows developers to code in an isolated environment  while testing and shipping specific error fixes/features but maintains the main codebase
